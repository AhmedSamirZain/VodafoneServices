# 🤖 VodafoneServices — بوت خدمات فودافون

بوت تليجرام لإدارة خدمات "أنا فودافون" (فليكسات، باقات، تحويل، خدمات...).
البوت **بوت واحد** بيخدم المستخدمين ولوحة تحكم الأدمن في نفس الوقت.

---

## 🔐 الإعدادات — سِرّين بس

البوت كله محتاج سِرّين (Secrets) **بس**:

| الاسم | القيمة | مثال |
|---|---|---|
| `BOT_TOKEN` | توكن البوت من [@BotFather](https://t.me/BotFather) | `123456789:AAExample...` |
| `ADMIN_IDS` | أرقام تليجرام الأدمن (واحد أو أكتر، مفصولة بفواصل) | `111111111, 222222222` |

- أول رقم في `ADMIN_IDS` = المطور الأساسي (`DEV_ID`)، والباقي أدمن بنفس الصلاحيات.
- مفتاح تشفير كلمات المرور (`VAULT_KEY`) **بيتشتق تلقائياً من `BOT_TOKEN`** — مش محتاج تضيفه.
  (لو حبيت مفتاح مستقل، ضيف `VAULT_KEY` وهو هيتقدّم على المشتق.)
- تسجيل الدخول في فودافون شغال من غير أي إعدادات إضافية (مش محتاج `VODA_CLIENT_SECRET`).
- أي إعداد تاني (سعر الاشتراك، رقم فودافون كاش، اسم قاعدة البيانات...) اختياري وله قيمة
  افتراضية، وممكن تغيّره من `.env` أو وقت التشغيل من لوحة التحكم.

### على Streamlit Cloud

افتح تطبيقك ← تبويب **Secrets** وحط:

```toml
BOT_TOKEN = "123456789:AAExample..."
ADMIN_IDS = "111111111, 222222222"
```

بعدين اعمل **Restart** للتطبيق.

### على جهازك

```bash
cp .env.example .env      # واملأ القيمتين
pip install -r requirements.txt
python Vodafone_fixed.py
```

> ⚠️ ملف `.env` ممنوع يترفع على جيت (مضاف في `.gitignore` أصلاً).

## 🚀 التشغيل

| الطريقة | الأمر |
|---|---|
| Streamlit Cloud | الملف الرئيسي: `streamlit_app.py` |
| من جهازك (كونسول) | `python Vodafone_fixed.py` |

`/start` من أي حساب أدمن → بيفتح **لوحة التحكم**.
`/start` من أي مستخدم عادي → بيفتح **قائمة الخدمات**.

---

## 📁 الملفات

| الملف | الوظيفة |
|---|---|
| `Vodafone_fixed.py` | كود البوت الأساسي (المستخدمين + لوحة التحكم) |
| `streamlit_app.py` | نقطة دخول ستريمليت + صفحة حالة الإعدادات |
| `config.py` | قراءة `BOT_TOKEN` و `ADMIN_IDS` واشتقاق مفتاح التشفير |
| `security.py` | خزنة كلمات المرور المشفرة، تقييد المحاولات، سجل التدقيق |
| `tests/` | اختبارات الإعدادات وتحويل أوامر الأدمن |
